# Organic Store — starter website

## Run locally
1. Extract the ZIP.
2. Open the `organic_store_starter` folder in VS Code.
3. Open `index.html` in a browser (or use the VS Code Live Server extension).

## Included
- Responsive traditional Indian-inspired storefront
- Sample categories and products
- Product search and category filters
- Cart with quantity controls and localStorage persistence
- WhatsApp order message flow
- Checkout details form that prepares a WhatsApp order request

## Before using with real customers
- Replace `YOUR ORGANIC STORE` in `index.html` with your approved brand name.
- Replace `91XXXXXXXXXX` in `app.js` with your business WhatsApp number.
- Replace sample product names, prices, images and descriptions with accurate product information.
- Add verified business contact, address, shipping, return, privacy and terms information.
- This is a frontend starter/demo. It does NOT yet include secure customer accounts, a server/database, admin dashboard, inventory sync, payment processing, tax/shipping calculation, or order confirmation. Do not accept real online payments through this demo.
- For a production launch, connect a backend/database (e.g. Supabase/PostgreSQL), authenticated admin access, and a payment provider such as Razorpay using server-side order creation and verified payment webhooks. Never store payment secrets in frontend JavaScript.
- Only make organic/certification, purity, sourcing and health claims that you can substantiate and are legally permitted to use.
